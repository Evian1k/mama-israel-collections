Project: Production-quality clothing e-commerce site (Phase 1 = complete frontend, API-first architecture, zero fake production data; Phase 2 = external REST backend on PostgreSQL).

Conventions every agent MUST follow:
- Next.js 16 App Router + TypeScript strict. Tailwind CSS 4 + shadcn/ui (New York). TanStack Query for server state, Zustand for client state. lucide-react icons only.
- Brand: warm cream background, deep burgundy primary (#7A2235), gold accent (#B98A4E), espresso text. Display font: Playfair Display (`font-display`), body: Jost (`font-sans`).
- NEVER fake production data. Empty/loading/error states everywhere. Dev sample data only via opt-in admin "dev data" actions.
- All data access via `src/services/api/*` (never fetch directly in components).
- Do not start a second dev server (one is running on :3000). Never run `bun run build`.
